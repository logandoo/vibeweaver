# Acceptance Criteria — Variable Length Quantity (encode/decode)

1. encode([0x0]) returns [0x0] (zero → single zero byte).
2. encode of any value in 0..0x7F returns a single byte equal to that value (0x40 → [0x40], 0x7F → [0x7F]).
3. encode([0x80]) returns [0x81, 0x0] (continuation bit 0x80 set on every byte except the last).
4. encode([0x2000]) returns [0xC0, 0x0]; encode([0x3FFF]) returns [0xFF, 0x7F].
5. encode([0x4000]) returns [0x81, 0x80, 0x0]; encode([0x100000]) returns [0xC0, 0x80, 0x0].
6. encode([0x200000]) returns [0x81, 0x80, 0x80, 0x0]; encode([0xFF000000]) returns [0x8F, 0xF8, 0x80, 0x80, 0x0].
7. encode([0xFFFFFFFF]) returns [0x8F, 0xFF, 0xFF, 0xFF, 0x7F] (max 32-bit unsigned).
8. encode([]) returns [].
9. encode of multiple values concatenates each value's VLQ in order ([0x4000, 0x123456] → [0x81,0x80,0x0,0xC8,0xE8,0x56]).
10. encode([-1]) raises ValueError.
11. encode([0x100000000]) raises ValueError (2**32 exceeds 32-bit unsigned restriction).
12. decode([0x7F]) returns [0x7F].
13. decode([0xC0, 0x0]) returns [0x2000]; decode([0xFF, 0xFF, 0x7F]) returns [0x1FFFFF].
14. decode([0x81, 0x80, 0x80, 0x0]) returns [0x200000].
15. decode([0x8F, 0xFF, 0xFF, 0xFF, 0x7F]) returns [0xFFFFFFFF].
16. decode([]) returns [].
17. decode([0xFF]) raises ValueError with message exactly "incomplete sequence".
18. decode([0x80]) raises ValueError with message exactly "incomplete sequence" (incomplete even when value is zero).
19. decode of a concatenated multi-value sequence returns the ordered value list ([0xC0,0x0,0xC8,0xE8,0x56,0xFF,0xFF,0xFF,0x7F,0x0,0xFF,0x7F,0x81,0x80,0x0] → [0x2000, 0x123456, 0xFFFFFFF, 0x0, 0x3FFF, 0x4000]).
20. Round-trip: decode(encode(v)) == v for the full canonical table and a randomized sweep of 32-bit values; encode(decode(x)) == x for canonical encodings.
