Generated by `python3 scripts/eval_token_report.py --out docs/EVAL_TOKENS.md` from every
`tests/eval/**/trajectory.json` (opencode `step_finish` events). `cost.json` `tokens` was
null in all existing runs; nothing here is estimated.

Caveats:
- One served model for the lab arms (qwen3.8-27b on vLLM, **no prompt caching**: cache reads = 0).
  On a provider with prompt caching the dollar ratio between arms is much smaller than the token ratio.
- "no tokens" = runs without an event stream — almost all are agent timeouts, whose output
  `run_process_group` discards (eval_run.py). Medians cover only runs with data; timed-out runs
  are typically the longest, so their arm's median is an underestimate.
- Families: `compliance` = `g3_comp*` (hidden tests check skill-format artifacts), `teeth` = `*teeth*`,
  `capability` = everything else. Verdicts are the harness `verdict` field.
